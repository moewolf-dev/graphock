# Security Policy

Do not report secrets, vulnerabilities, exploit details, or private user data in public issues or pull requests.

Use a private maintainer channel for security reports. Until a dedicated public security contact is published, contact the repository owner directly through the GitHub organization.

Community templates are treated as untrusted content. Validators and maintainers may reject templates that include secrets, unsafe links, suspicious prompts, path traversal, executable payloads, or private data.
