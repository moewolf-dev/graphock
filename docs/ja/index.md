# Graphock ドキュメント

Graphock は、ファイルの取り込み、処理タスクの設定、元ファイルと生成結果の関係の探索を行うデスクトップのワークスペースです。ウェブサイトは製品情報とダウンロードを提供し、デスクトップアプリの代わりにはなりません。

最初は自分で内容を確認できる、機密情報を含まない少数のファイルを使います。アプリをインストールしてログインし、利用可能なワークスペースを選択します。ファイルを取り込み、タスクに必要なサービスを設定して、生成結果を確認してからグラフで探索します。

- [デスクトップ画面の案内](../en/getting-started/tour-interface.md)
- [ファイルの取り込み](../en/get-data/index.md)
- [処理サービスの設定](../en/get-data/connect-sources.md)
- [最初のファイルグラフ](../en/getting-started/first-visualization.md)

ローカルとクラウドのワークスペースでは実行環境が異なります。ローカルサービスには稼働中の環境が必要です。外部サービスの料金とデータポリシーが適用されます。利用可否は設定とアカウント権限によって異なり、グラフだけでは抽出内容の正確さは保証されません。

旧ダッシュボードや共同編集の手順はアーカイブされています。英語で提供する詳細ガイドには、その言語を明記し、日本語訳として表示しません。
