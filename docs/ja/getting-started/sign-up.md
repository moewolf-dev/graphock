# 注册 Graphock

几分钟内创建您的免费 Graphock 账户并开始可视化您的数据。

## 创建账户

### 步骤1：访问注册页面

访问 [https://graphock.com/signup](https://graphock.com/signup) 或点击我们首页上的**注册**按钮。

### 步骤2：输入您的信息

提供以下详细信息：

- **电子邮件地址**：您的工作或个人电子邮件
- **密码**：创建一个强密码
- **全名**：您的显示名称
- **公司**（可选）：您的组织

### 步骤3：验证您的电子邮件

检查您的收件箱中的验证电子邮件。点击链接以激活您的账户。

### 步骤4：完成您的个人资料

添加可选信息以个性化您的体验：

- 个人资料图片
- 时区
- 首选语言

## 登录

创建账户后，您可以随时登录：

1. 前往 [https://graphock.com/login](https://graphock.com/login)
2. 输入您的电子邮件和密码
3. 点击**登录**

**提示**：勾选"记住我"以在您的设备上保持登录状态。

## 忘记密码？

如果您忘记了密码：

1. 在登录页面点击**忘记密码**
2. 输入您的电子邮件地址
3. 检查您的收件箱中的密码重置链接
4. 创建新密码

## 故障排除

### 没有收到验证电子邮件？

1. 检查您的垃圾邮件文件夹
2. 等待5-10分钟以进行投递
3. 请求新的验证电子邮件

### 电子邮件已注册？

如果您看到"电子邮件已注册"：

- 您可能已经有账户 - 尝试登录
- 或者如果您忘记了密码则重置密码

## 安全提示

- 使用强、唯一的密码
- 启用双因素身份验证（专业计划上可用）
- 不要分享您的凭据
- 从共享设备注销
