# 第一个可视化

使用此分步指南在 Graphock 中创建您的第一个图表。

## 开始之前

确保您有：

- ✅ Graphock 账户（如果没有，[注册](/ja/getting-started/sign-up））
- ✅ 数据文件（CSV、Excel 或 JSON）

**没有数据？** [下载我们的示例数据集](/ja/examples/sample-datasets)

## 步骤1：导入您的数据

### 选项 A：上传文件

1. 在仪表板中点击**新建项目**
2. 选择**上传数据**
3. 选择您的文件（CSV、Excel 或 JSON）
4. 等待导入完成

### 选项 B：连接到数据库

1. 点击**新建项目**
2. 选择**连接数据库**
3. 选择您的数据库类型（PostgreSQL、MySQL 等）
4. 输入您的连接详细信息
   - 主机
   - 端口
   - 数据库名称
   - 用户名/密码
5. 选择一个表以导入

## 步骤2：预览您的数据

导入后，您将看到数据预览：

```
┌─────────────────────────────────────────┐
│  数据预览：sales_data.csv          │
├─────────────────────────────────────────┤
│  ✓ 已导入 1,234 行                │
│  ✓ 检测到 5 列                 │

│  日期      │ 产品  │ 销售额 │ 地区 │
│  2024-01-01│ 小部件A │ 120   │ 北部│
│  2024-01-02│ 小部件B │ 95    │ 南部│
│  2024-01-03│ 小部件A │ 150   │ 东部│

```

**检查以下内容：**
- 列标题正确
- 数据类型看起来正确
- 没有关键数据丢失

## 步骤3：创建图表

1. 点击**添加可视化**
2. 选择图表类型（从**柱状图**开始）
3. 将字段拖放到：
   - **X轴**：日期
   - **Y轴**：销售额
   - **颜色**：产品

您的图表将立即出现！

## 步骤4：自定义您的图表

### 更改颜色

1. 点击图表
2. 在右侧面板选择**颜色**
3. 选择调色板或自定义颜色

### 添加标签

1. 在右侧面板点击**标签**
2. 启用**显示数据标签**
3. 选择标签格式

### 调整轴

1. 在右侧面板点击**轴**
2. 自定义标题、范围和格式
3. 添加网格线以提高可读性

## 步骤5：保存您的工作

1. 在右上角点击**保存**
2. 为您的可视化输入名称
3. 添加描述（可选）
4. 点击**保存**

## 步骤6：分享您的可视化

### 导出为图像

1. 点击**导出**
2. 选择**PNG**或**SVG**
3. 选择分辨率
4. 点击**下载**

### 获取可共享链接

1. 点击**分享**
2. 切换**公共链接**
3. 复制URL
4. 与任何人分享！

## 示例：构建销售图表

### 数据结构

| 日期 | 产品 | 销售额 | 地区 |
|------|------|-------|--------|
| 2024-01-01 | 小部件A | 120 | 北部 |
| 2024-01-02 | 小部件B | 95 | 南部 |
| 2024-01-03 | 小部件A | 150 | 东部 |
| 2024-01-04 | 小部件C | 200 | 西部 |

### 图表配置

- **类型**：柱状图
- **X轴**：日期
- **Y轴**：销售额
- **颜色**：产品
- **标题**："按产品的月度销售额"

### 结果

一个彩色的柱状图，显示每个产品随时间变化的销售趋势！

## 常见问题

### 数据没有显示？

- 检查字段是否分配给轴
- 验证数据类型正确
- 查找空值或空值

### 图表看起来错误？

- 尝试不同的图表类型
- 检查轴缩放
- 确保颜色字段有数据

### 看不到我的数据？

- 确认导入成功完成
- 检查数据预览是否有问题
- 验证您的数据集对于可视化来说不太大
