# 开始使用文件工作区

先选择几份不敏感、可以亲自核对内容的小文件。这样可以区分导入、任务与服务配置的问题。

## 第一次使用

1. 从官网下载适合操作系统和架构的桌面安装包。
2. 在桌面应用登录，并选择账号可用的本地或云工作区。
3. 在文件页面导入文件，核对列表中的名称、类型和大小。
4. 在设置中配置任务需要的运行环境和服务商。
5. 返回本地或云工作区，在那里选择输入文件并按下方步骤提交任务；检查输出，抽查提取字段是否与原文件一致。
6. 打开图页面查看任务关系或结构化数据；打开文件星系浏览工作区文件的联系。

## 提交第一个任务

1. 在选定的工作区，通过导入区域添加小文件或选择已有输入。检查已选输入列表；文件出现在“文件”页面中，不等于已被选为本次任务输入。
2. 选择合适的功能/模板，或在提示词输入框填写请求。对可亲自阅读的文本文件，可以先要求生成简短摘要，再与原文比较。
3. 核对提示词下方的模型、解析服务和输出类型，使用已配置模型或有效默认值，先处理模型/服务警告。
4. 点击提示词右下角的向上箭头提交按钮，其标签为“开始任务”。若按钮不可用，检查已选输入、请求或功能选择，以及配置警告。若文件支持检查阻止提交，按提示调整输入或处理设置。
5. 在任务/结果区域查看任务状态和生成文件。提交不等于完成；打开输出核对后，再扩大批量。

## 扩大批量前

确认所选服务可用、模型支持输入类型、输出格式符合实际用途。成功导入不代表所有处理适配器都支持该文件。先用小任务解决服务限制或错误，再扩大文件数量。

继续阅读[导入文件](../get-data/index.md)和[配置服务](../get-data/connect-sources.md)。
