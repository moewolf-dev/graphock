# 检查第一个文件图

本指南使用桌面图视图，不依赖未经验证的仪表盘图表编辑器。

## 准备结果

导入可亲自阅读的小文件，配置受支持的服务与任务。打开图之前先核对生成输出。如果实体或字段提取错误，应修正任务或输入，可视化不会自动纠正内容。

## 任务关系

在图页面选择任务关系模式，查看当前工作区的文件与任务，沿关联理解输出来源。需要核对真实内容时，返回对应文件或任务视图。

## 数据分析

数据分析查询的是选中的图数据库；仅将文件导入“文件”列表不会自动填充此视图。

1. 打开图页面并选择数据分析，在 Graph DB 列选择当前工作区的图数据库；没有数据库时选择导入。
2. 在导入对话框中选择可用的已导入文件或任务输出。建议先使用字段含义清楚的小型 CSV；被禁用的源文件不适用于此导入流程。
3. 进入 Generate Blueprint，核对节点标签、标识字段、属性和边映射，修正映射并处理报告的问题后再导入。
4. 选择目标数据库或填写新数据库名称，点击 Start Import，逐个检查文件结果。部分成功不等于全部成功；需要时使用 Retry Failed Imports 重试失败项。
5. 选择数据库，在查询构建器中选择节点、关系与过滤条件，执行查询，再检查返回的节点和连线。

根据节点数量或缺失连接得出结论前，先检查查询条数上限及 Truncated 标记。空结果可能来自数据库选择或过滤条件，不一定是渲染故障。重要关系仍应与源材料核对。

## 文件星系

打开文件星系，选择文件节点并查看连接。通过文件可用动作检查内容。空地图可能只是当前工作区缺少相关文件，应先核对工作区，再调整渲染设置。
