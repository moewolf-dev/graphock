# 安装并登录

从官网下载匹配操作系统和处理器架构的桌面安装包。遇到问题时请记录版本，安装包和账号可用权限可能随版本变化。

## 登录流程

在应用的登录页面启动浏览器认证。使用已有账号完成认证，按提示返回桌面应用。官网控制台登录与桌面回调的目标不同，不要用无关网页地址替换桌面回调。

如果浏览器认证完成后应用仍未登录，请从应用重新发起登录，并检查操作系统是否允许回调打开已安装的应用。请勿在公开问题中粘贴访问令牌或回调 URL。

## 工作区权限

当前桌面应用要求登录。云工作区和处理服务的可用性由账号权限及配置决定。成功登录并不表示全部服务已经配置，或云处理已向该账号开放。

登录后阅读[界面导览](./tour-interface.md)。支持请求中不要附上凭据、令牌或私有文件。
