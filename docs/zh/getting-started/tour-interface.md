# 桌面界面导览

先选择工作区，使文件、任务和可视化指向同一上下文。

| 页面 | 用途 |
| --- | --- |
| 本地／云工作区 | 选择账号可用的运行上下文，选择任务输入、填写请求并核对结果。 |
| 文件 | 导入文件，查看名称、大小、类型和可用预览动作。 |
| 任务 | 查看处理工作及生成结果。 |
| 模板 | 选择已配置的任务模板。 |
| 图 | 在任务关系与数据分析模式之间切换。 |
| 文件星系 | 浏览文件空间及关联。 |
| 设置 | 配置服务商、运行环境等。 |

## 导入与选择输入是两步

“文件”页面用于查看已导入资料及预览操作。处理请求在工作区创建：确认已选输入，选择功能或填写提示词，核对模型/服务后使用提交箭头。工作区可以采用双栏或三栏布局，面板位置可能不同。操作见[第一个任务步骤](./index.md#提交第一个任务)。

## 分清图的两种模式

任务关系关注文件与处理任务的联系；数据分析关注结构化图数据。一个视图中的节点不代表其他视图一定提供同类信息。

页面为空时，先检查工作区及相关文件／结果是否存在。示例数据用于学习界面，不证明应用处理过自己的文件。第一次验证应使用能自行核对的小文件。

继续阅读[检查第一个文件图](./first-visualization.md)。
