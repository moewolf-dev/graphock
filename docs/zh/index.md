# Graphock 使用文档

Graphock 是面向文件处理的桌面工作区：导入文件，配置处理任务，再探索来源与生成结果之间的关系。官网提供下载和产品信息，并不等同于桌面的文件处理工作区。

## 从一组小文件开始

1. [安装并登录](./getting-started/sign-up.md)。
2. [认识桌面界面](./getting-started/tour-interface.md)。
3. [导入文件](./get-data/index.md)，检查名称、类型和大小。
4. [配置处理服务](./get-data/connect-sources.md)。
5. [检查结果及文件图](./getting-started/first-visualization.md)。

## 当前产品范围

桌面应用区分本地与云工作区。可用处理能力取决于运行环境、配置的适配器和账号权限。本地服务需要本地运行环境；外部服务有自己的费用、用量限制和数据政策。本地工作区并不意味着所用服务商一定在本地运行。

Graphock 提供任务关系、结构化数据图分析和文件星系。可视化不能证明提取内容正确，请核对源文件。旧图表编辑、仪表盘与协作文档已退出当前指南；原 URL 保留明确的归档说明，不再提供未经验证的操作步骤。
