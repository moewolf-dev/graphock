# 检查输入与输出格式

导入、预览、解析和模型输入是独立能力。文件可以出现在工作区，而特定任务仍不支持其内容。

## 处理之前

- 核对名称、类型和大小；有预览动作时检查源文件。
- 确认任务和适配器接受输入类型，图像 OCR 与纯文本模型的要求不同。
- 对表格和结构化文件抽查缺失值、类型与字段是否一致。

## 处理之后

检查实际输出。如果任务要求结构化数据，确认格式有效且必要字段齐全。对照原文件核对提取值，并保留来源关系，方便追溯错误字段。

大小、格式和服务载荷限制取决于任务与运行环境。本指南不宣称统一文件上限或任意数据库、文档格式都受支持。
