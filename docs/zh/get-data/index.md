# 导入文件

在桌面的文件页面使用导入动作选择本地文件。先导入少量文件，核对名称、类型和大小，再运行批量处理。

## 预览与检查

文件提供预览动作时，检查源内容。预览能力取决于文件类型及其能力。文件列表中的元数据与实际内容不同：导入成功不代表所有解析器或模型都能处理该格式。

保留原始文件以核对生成结果。任务失败时记录应用版本、文件类型和错误类别，请勿向公开问题附上私有文件或凭据。

## 本地与远程处理

文件来源负责提供输入，模型和处理适配器负责执行任务，两者是不同配置。选择本地工作区不等同于选择本地模型。处理敏感材料前，请检查任务的运行环境、服务商及其数据政策。

旧数据库连接教程不是当前已核对的导入流程。请使用安装版本实际提供的文件导入和服务设置。

阅读[格式检查](./data-formats.md)和[配置服务](./connect-sources.md)。
