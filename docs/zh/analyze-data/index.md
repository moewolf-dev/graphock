# 审阅图数据和文件关系

区分图上展示的关系与内容本身的准确性。可视化帮助理解来源和结构，不能替代核对。

## 来源审阅

在图的任务关系模式中找到源文件、任务与生成输出。结果不完整或异常时，检查任务上下文。应依据源材料评估结果，而不是因为它出现在图上就接受它。

## 结构化数据审阅

数据分析读取选中的图数据库。通过导入对话框选择可用文件，核对生成的蓝图及节点/边映射，再导入目标数据库。查询前检查每个文件的失败情况；文件已在“文件”列表中，不代表它已经进入图数据库。

选择数据库，构建并执行查询，再检查返回的节点与连线，留意重复实体、缺失连接及与输入不符的关系。解释数量或空视图前，核对过滤条件、查询条数上限及 Truncated 标记；有限查询结果不等于完整数据库。

重要内容要直接与源文件核对，图不是独立的事实来源。操作见[导入与查询步骤](../getting-started/first-visualization.md#数据分析)。

## 文件探索

文件星系提供工作区文件与关联的另一种视图。可以先浏览，再回到文件或任务核对实际内容。它不是统计显著性检验，也不保证语义相似性。

旧统计计算和销售仪表盘步骤未按此桌面流程验证，对应 URL 已标记归档。起点见[第一个文件图](../getting-started/first-visualization.md)。
