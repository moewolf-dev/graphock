# 快速开始

欢迎使用 Graphock！本指南将帮助您在几分钟内开始使用。

## 什么是 Graphock？

Graphock 是一个强大的数据可视化平台，让您能够：

- 🎨 从您的数据创建令人惊叹的图表和图形
- 🔍 分析趋势、模式和洞察
- 👥 与您的团队分享和协作
- 📱 在任何地方访问您的可视化

## 开始之前

### 系统要求

Graphock 完全在云端运行 - 无需安装！您只需要：

- 现代网页浏览器（Chrome、Firefox、Safari 或 Edge）
- 稳定的互联网连接
- 免费的 Graphock 账户

## 快速概览

### 1. 注册

[创建您的免费账户](/getting-started/sign-up) 开始使用。只需一分钟！

### 2. 导入您的数据

连接到电子表格、数据库或 API。我们支持：

- Excel 和 CSV 文件
- JSON 数据
- 数据库（PostgreSQL、MySQL 等）
- 网络 API

### 3. 创建可视化

使用我们的拖拽界面构建图表、图形和仪表板。

### 4. 分享洞察

发布您的工作并与团队成员实时协作。

## 我可以可视化什么？

Graphock 可以处理：

- 小型数据集（数十行）
- 中型数据集（数千行）
- 大型数据集（数百万行）

### 推荐的数据格式

- **结构化数据**：具有清晰标题的表格
- **时间序列数据**：日期和时间戳
- **分类数据**：组和类别
- **地理数据**：位置和坐标
