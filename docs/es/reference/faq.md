# 常见问题

关于 Graphock 的常见问题解答。

## 常见问题

### 什么是 Graphock？

Graphock 是一个专为业务分析师、研究人员以及任何需要将数据转化为可操作洞察的人设计的可视化平台。

### Graphock 是免费的吗？

是的！Graphock 为个人和小型项目提供免费计划。我们还提供具有额外功能的 Pro 和企业版计划。

### 支持哪些浏览器？

Graphock 支持所有现代网页浏览器，包括 Chrome、Firefox、Safari 和 Edge。

## 数据和可视化

### 支持哪些文件格式？

Graphock 支持 CSV、Excel、JSON 和 TSV 文件。我们还可以连接到数据库和 API。

### 我可以导入多少数据？

免费计划：最多 50,000 行
专业计划：最多 1,000,000 行
企业版：无限制

### 有哪些图表类型可用？

我们支持柱状图、折线图、网络图、散点图、饼图、地图等。

## 账户和计费

### 如何升级我的计划？

在您的账户中前往设置 > 计费以查看和更改您的计划。

### 我可以取消订阅吗？

是的，您可以随时取消订阅。您的计划将保持活跃直至计费周期结束。
