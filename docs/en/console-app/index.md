# Graphock Console App

Graphock Console is the desktop application. Files, tasks, graph databases and local settings live on your Mac; the website is for downloads, account pages and documentation, not for processing files.

## Availability at a glance

| Capability | Status | Notes |
| --- | --- | --- |
| Local document engine, Apple Vision OCR and Apple native reader | **Available** | Included in both macOS editions; runs on the device |
| Workspace, Files, Settings | **Available** | The Direct build needs an account; the App Store edition does not |
| Sign-in through graphock.com | **Available** | Required at launch for Direct; only for cloud parsing in the App Store edition |
| Cloud parsing | **Requires sign-in** | Monthly allowance, shared by the signed-in account |
| Tasks page, Templates, Graph, File Galaxy, Reports | **Direct: requires Pro** | Included with the Mac App Store edition |
| Direct Pro purchase | **Coming soon** | No price is shown until checkout is live |
| Mac App Store edition | **Not published yet** | One-time paid download, USD 39.00 |
| Windows and Linux builds | **Not available** | Packaging placeholders only |
| Sale in mainland China | **Not available** | Neither edition is sold there |

Availability describes what the application checks at runtime. A feature can still be unavailable because of your build, your account, your edition or the service you configured.

## What the desktop app does not do

- It does not process files on the website. Website pages describe the product; the desktop app performs the work.
- It does not silently substitute a different parser when a format is unsupported. A blocked file is reported, not skipped.
- It does not grant Pro from a client-side claim. A Direct entitlement is verified by the Graphock service.
- It does not share a Direct Pro purchase with the Mac App Store edition.
- It does not make cloud results local. A local workspace and a cloud workspace have separate runtimes.

Graphock is under active development. This guide marks planned or unavailable capabilities explicitly instead of describing them as shipped.
