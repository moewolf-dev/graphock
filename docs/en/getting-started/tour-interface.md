# Tour the Interface

Get familiar with Graphock's user interface and navigation.

## Main Dashboard

When you log in, you'll see the main dashboard:

```
┌─────────────────────────────────────────────────────┐
│  [Logo]  Graphock      [Search]  [User Profile]   │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Welcome back, Alex!                                │
│                                                     │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│  │ Project 1│  │ Project 2│  │ Project 3│        │
│  └──────────┘  └──────────┘  └──────────┘        │
│                                                     │
│  [+ New Project]                                   │
└─────────────────────────────────────────────────────┘
```

### Top Navigation Bar

- **Logo**: Click to return to dashboard
- **Search**: Find projects, data, and help
- **User Profile**: Settings, sign out, and account

## Project View

Open any project to enter the workspace:

```
┌─────────────────────────────────────────────────────┐
│  [←] Project Name    [Save] [Share] [Export]      │
├─────────┬──────────────────┬───────────────────────┤
│         │                  │                       │
│ Data    │   Canvas         │   Properties Panel   │
│ Panel   │                  │                       │
│         │   [Chart]        │   • Chart Type       │
│ Table   │                  │   • Colors           │
│         │                  │   • Labels           │
│ Fields  │                  │   • Axes             │
│         │                  │                       │
│ [Drag]  │                  │                       │
│         │                  │                       │
└─────────┴──────────────────┴───────────────────────┘
```

### Left Panel: Data Panel

Shows your data sources and available fields:

#### Data Sources Tab
- List of all imported tables
- Database connections
- API endpoints

#### Fields Tab
- Available columns from your data
- Data types (number, text, date)
- Field metadata

### Center: Canvas

Your visualization workspace:

- **Add Visualization**: Create new charts
- **Drag to rearrange**: Move charts around
- **Resize**: Adjust chart dimensions
- **Zoom**: Zoom in/out for better view

### Right Panel: Properties Panel

Customize your visualization:

#### Chart Section
- **Type**: Bar, line, pie, etc.
- **Colors**: Color palette and custom colors
- **Labels**: Show/hide data labels
- **Tooltips**: Hover information

#### Axes Section
- **X-Axis**: Field, title, format, range
- **Y-Axis**: Field, title, format, range

#### Filters Section
- Add filters to your data
- Date ranges
- Category selections

## Toolbar Actions

### Save
- Save your current work
- Save as new version

### Share
- Create shareable link
- Set permissions (view/edit)
- Invite team members

### Export
- Download as PNG/SVG image
- Export data as CSV
- Export report as PDF

### Settings
- Project settings
- Data refresh settings
- Theme preferences

## Keyboard Shortcuts

Speed up your workflow with shortcuts:

| Action | Windows/Linux | Mac |
|--------|---------------|-----|
| Save | Ctrl+S | Cmd+S |
| Undo | Ctrl+Z | Cmd+Z |
| Redo | Ctrl+Y | Cmd+Y |
| Delete | Delete | Delete |
| Copy | Ctrl+C | Cmd+C |
| Paste | Ctrl+V | Cmd+V |
| Zoom In | Ctrl+= | Cmd+= |
| Zoom Out | Ctrl+- | Cmd+- |
| New Project | Ctrl+N | Cmd+N |
