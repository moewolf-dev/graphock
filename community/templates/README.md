# Community Templates

Each template must live in its own directory:

```text
community/templates/<template-code>/
  template.yaml
  README.md
  prompt.md
```

`template.yaml` must conform to `schemas/community-template-manifest.schema.json`.

Trusted publication metadata is generated by GitHub Actions after a pull request is merged. Do not put `source_repo`, `source_path`, `source_pr_url`, `source_commit_sha`, `source_merged_at`, or `author_github` in `template.yaml`.

Run validation before opening a pull request:

```bash
npm ci
npm run validate
```

External template submission is not open until the owner approves the SPDX license allowlist in `LICENSE_POLICY.md`.
