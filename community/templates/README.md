# Community Templates

Each template must live in its own directory:

```text
community/templates/<template-code>/
  template.yaml
  README.md
  prompt.md
  locales/<locale>.md        # optional catalog title/description translations
```

`template.yaml` must conform to `schemas/community-template-manifest.schema.json`.
Localized catalog copy is optional and supports `en`, `zh`, `fr`, `es`, and `ja`. Put one language in each Markdown file, beginning with a single `#` title and followed by a short description paragraph. These files only localize the catalog card; they do not translate or change the executable prompt. When a translation is missing, the website falls back to English catalog text and then to the API listing.

Keep localized files under 64 KB, use LF line endings, and do not add raw executable HTML or secrets. The website sync job imports only the title and first description paragraph; prompt text, runtime config, and template assets are never copied to the website catalog.

Trusted publication metadata is generated by GitHub Actions after a pull request is merged. Do not put `source_repo`, `source_path`, `source_pr_url`, `source_commit_sha`, `source_merged_at`, or `author_github` in `template.yaml`.

Run validation before opening a pull request:

```bash
npm ci
npm run validate
```

External template submission is not open until the owner approves the SPDX license allowlist in `LICENSE_POLICY.md`.
