# Community

Community content is reviewed through pull requests. The first supported content class is community templates under `community/templates/`.

Do not submit secrets, personal data, private customer data, executable payloads, or files that you do not have the right to redistribute.

Template catalog metadata may include optional display translations under `community/templates/<template-code>/locales/` for English, Chinese, French, Spanish, and Japanese. See [template contribution guidance](./templates/README.md) for the file format and fallback behavior. External template submissions remain subject to the owner-approved license policy.
