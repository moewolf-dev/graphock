# Contributing

Thank you for contributing to Graphock.

## Community Template Pull Requests

Each template lives in its own directory under `community/templates/` and must include a `template.yaml` file. Optional files such as `README.md` or prompt files must stay inside that template directory.

Before opening a pull request:

```bash
npm ci
npm run validate
```

## Required Contributor Confirmations

By submitting a pull request, you confirm that:

- you have the right to contribute the prompt, configuration, examples, and documentation;
- you agree to distribute the submitted template under the SPDX license declared in `template.yaml`;
- you did not submit secrets, API keys, personal data, private customer data, copyrighted datasets that cannot be redistributed, or model artifacts that cannot be redistributed;
- trusted source metadata such as repository, path, pull request URL, commit SHA, merge time, and GitHub author will be generated by the repository workflow, not authored in `template.yaml`.

## Review and Removal

Maintainers may request changes, reject submissions, or remove published templates for security, licensing, privacy, quality, or product-fit reasons.
